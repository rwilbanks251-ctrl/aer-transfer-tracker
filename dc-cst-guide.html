Data Capture — CST Notification Guide

Quick reference only, not a controlled EHS procedure.

When an order finishes Data Capture, the CST is told how it went and sent the matching report. Which report depends on one thing: whether a validation file was loaded against the order.

The step at a glance

  1. Order completes Data Capture
  2. Identify the CST for that account
  3. Run the Check In Validation Report
  4. If nothing comes back, pull the Audit Report - Basic
  5. Send the Teams message to the CST: Data Capture is done here
  6. The CST messages the Warehouse Supervisor to hold or continue

1. Confirm the order is data captured

All assets on the work order have been captured and the order has left the Data Capture step. Do not send anything while material is still being captured: the report will be incomplete and the CST will be working from the wrong numbers.

Note the work order number. It appears in every message below.

2. Identify the CST

The CST is named on the order itself.

  1. In the search bar at the top right, set the dropdown to Inbound Order, enter the work order number and open the order.
  2. On the Basic Info tab, look at Internal Resources in the left-hand column.
  3. The person listed as Account Administrator is the CST.

Do not use the Account Owner directly above them. That is a different role.

3. Run the Check In Validation Report

Do not go hunting for a validation file first. Running this report is the check. If a file was loaded against the order, the report compares it against what we captured. If there was none, the report comes back with nothing, and that is your answer.

  1. From the Makor home screen, go to Reports > Operations.
  2. Find Check In Validation Report. Its description reads "Compares Receiving Assets with Validation File". It is the first row.
  3. Click View.
  4. Enter the work order number in the Order Id box at the top.
  5. Press View Report.
  6. To send it on, export it to Excel using the save icon in the report toolbar.

If you get a comparison, read it before sending: were there discrepancies, or not? That decides which message you use in step 5.

Most orders will not have a validation file. On a recent large account, 19 of 68 orders had one.

4. If nothing came back: Audit Report - Basic

  1. In the search bar at the top right, set the dropdown to Inbound Order.
  2. Enter the work order number and search.
  3. Open the order from the results.
  4. On the Basic Info tab, look down the right-hand column for Reports, just under Order Status.
  5. Open the Report dropdown and choose Audit Report - Basic. It is the first entry in the list.
  6. Set Type to Excel. (CSV and PDF are also offered.)
  7. Press View. The report downloads.

Take care in that dropdown. Audit Report - Data Security, Audit Report - Detailed and Audit Report - Settlement sit directly beneath Basic: four near-identical names in a row. They are different reports. Do not substitute one for another.

5. Send the Teams message

Replace #1234 with the real work order number, and attach the report you named. The message and the attachment must match.

No validation file

Hello CST, Work Order #1234 was completed in Data Capture and there was no validation file present, here is the Audit Report - Basic.

Validation file, no discrepancies

Hello CST, Work Order #1234 was completed in Data Capture and a validation file was present, there were no discrepancies when compared to the validation file, here is the Check In Validation Report.

Validation file, discrepancies found

Hello CST, Work Order #1234 was completed in Data Capture and a validation file was present, there were discrepancies when compared to the validation file, here is the Check In Validation Report.

Send the message as written. The wording tells the CST three things at once: that capture is finished, whether there was anything to check against, and whether it matched.

6. What happens next

Your part ends with the message in step 5. From there the CST messages the Warehouse Supervisor for the facility holding the material, who either places the order on hold or lets processing continue. Data Capture does not send that message and does not need to chase it.

What the CST sends (for reference)

These go from the CST to the supervisor, not from Data Capture.

On hold

Hello Warehouse Supervisor, Work Order #1234 needs to be placed on hold until further update.

Clear to continue

Hello Warehouse Supervisor, Work Order #1234 is clear to continue processing.

If the CST does not reply

If the CST has not replied by the time the order reaches Tracked Recycling, it is processed in its normal priority. Silence is not a hold: only an explicit instruction from the CST stops an order. Do not park material or pause processing while waiting for an answer.

Data Capture does not place orders on hold, release them, or act on a customer instruction.
